Updating an Editor X Site to the Studio Editor
Editor X is transitioning to Wix Studio, the web creation platform for agencies and enterprises. Starting November, we will begin a gradual process of automatically moving Editor X sites to the Studio Editor.If you wish to perform this update on your own, before this date, you can do so directly from your editor. This update is seamless—no rebuild required, and the live site stays exactly the same.
In this article, learn more about:
Important information about this update Updating a site from Editor X to the Studio Editor Frequently asked questions (FAQs)Things to know about this updateBefore updating to the Studio Editor, learn what happens to every part of the site, as well as the new features you're about to unlock. Your live site shouldn't be affectedThe live version of the site stays exactly the same as you perform this update - no downtime whatsoever. Your dashboard, SEO and site settings will be savedThis update does not affect the site's current settings. Any data you have in the dashboard (e.g. contacts, automations, inbox) is safe and secure. This also includes any SEO settings you defined for the site. Premium plans, domains and other subscriptions will stay active and connectedAll Premium plans will stay active connected to their sites. This means you continue to benefit from all the features of your existing Editor X pricing plan, for as long as you choose to renew it. We’re also offering the option to switch to a Wix Studio plan, but note that this may mean losing some existing features.Any assets and saved libraries will automatically move to StudioYour assets and design libraries from Editor X will automatically copy over to the Studio Editor. Note: The only assets that are not copied are vertical sections, as they are not supported in the Studio Editor. Velo remains as is, or you can use the new Wix IDEWix Studio allows you to continue writing code directly in the editor, or locally, using Git Integration. It also expands your coding environment options with the Wix IDE, a VS Code-based IDE that lets you edit your site's code in your browser.With Wix IDE you can:
Code in a familiar, full-fledged IDE. Collaborate with other developers and work in parallel. Access the Wix AI Assistant for help with writing and debugging Velo code. Code in a separate window from the editor to prevent screen clutter.Learn more about the Wix IDE.Your sites and team will switch to a new Wix Studio workspace, which includes the same benefits and features, plus moreIf you haven’t yet switched to the new workspace - your sites and team will be automatically switched.This brand new workspace lets you and your team efficiently manage multiple sites, create reusable custom templates and apps, and benefit from tailor-made solutions for agencies – client handover kits, a Customer Care dashboard and a visible product roadmap.Changes to vertical sectionsCurrently, vertical sections cannot be added in the Studio Editor. If the site you're updating already has vertical sections, you will still see them on the site but won't be able to edit them (only remove). Tip: You can still adjust any child elements in the vertical section. As a workaround, you can remove the existing vertical section and use a container to achieve a similar effect. Click here to see the full stepsChanges to image scroll effectsIf an image has a scroll effect (Parallax image effect, Reveal image effect), it remains the same on the live site. However, if you want to apply a different animation or effect from our robust offering, you will need to delete the old image scroll effect first.In addition, if you have an image with both a scroll effect and a click / hover interaction, keep in mind – you won’t be able to change or customize the animation unless you remove both.Note: Once you delete an old image scroll effect, it is not possible to re-add it.Remember the Animation panel in Editor X? You can find those entrance animations, and many new ones (like loop and scroll), under Animations and Effects in the Inspector panel.As part of this update, we revisited some old entrance animations and gave them a fresh look and feel (bounce, arc and turn). If you have elements with the previous versions of these animations, we invite you to check out our trendy new collection.Changes to pinned and sticky sectionsIf the Editor X site includes sections that are pinned but set differently per breakpoint, you'll see slight changes in the Studio Editor:  
If the pinned section was set to overlap with the next section on the primary breakpoint, but not on all breakpoints - the pinned section will overlap the next section on all breakpoints in the Studio Editor.  If the pinned section was set to not overlap with the next section on the primary breakpoint, but not all on breakpoints, it will turn to a Sticky section on all breakpoints in the Studio Editor. This also means the section won't overlap the next section on any breakpoint.Changes to click and hover interactions A few components that supported click and hover interactions in Editor X, no longer support them in the Studio Editor. If the site you're updating includes interactions on these components, the interactions move over successfully and will continue to function on the live site. You'll still be able to edit the interactions but if you remove them, it won't be possible to re-add them to the unsupported components. Tip:The Inspector panel is automatically set to the Advanced Size mode, which is similar to the settings you know from Editor X. To benefit from new Studio features like the responsive behaviors, change the sizing view preference to Set per Element.Updating a site from Editor X to the Studio EditorWhen an Editor X site is ready for the update, a pop-up appears as soon as you open the editor. Once you confirm the update to Wix Studio, the site moves over within minutes. Before you begin:
Close any other editor tabs that are open. In addition, make sure no one else is working on the site right now.  Only site owners can perform the update. We're working on making this option available for co-owners as well.  (Safari only) The Studio Editor supports Safari version 15 and up.To update a site:
Open the relevant site in Editor X.  (In the pop-up) Click Next. Click Update to Wix Studio.
Tip: The update may take a few minutes to complete.  (In the Studio Editor) Choose what to do next:
    
Browse Tutorials: Watch video tutorials to help you get acquainted with the new Studio Editor.
Tip: These videos are always available for you to go back to. In the editor, click the Video Tutorials icon  at the bottom left. Start Working: Exit the pop-up to explore the new and enhanced Studio Editor on your own. We recommend checking panels like the Inspector and Add Elements to see what's new.   What's next?Head over to the Wix Studio academy for all the courses, webinars and tutorials you may need. More specifically, check out our Elevating from Editor X to Wix Studio webinar.FAQsClick a question below to learn more about the update.Why should I update?Wix Studio includes the advanced Studio Editor, which has next-gen design functionalities such as responsive AI and open platform capabilities, so that you can deliver exceptional sites that will exceed your clients' vision. It also comes with a comprehensive suite of tools to simplify your workflow, including a centralized workspace to efficiently manage all your sites, your reusable assets, your team, subscriptions, domains and more. Note: Starting November, we will gradually begin automatically moving Editor X sites to the Studio Editor. However, you can perform this update manually by following the steps in this article. Why can't I see the option to update an Editor X site?The rollout of this update is gradual. If you can't see the option in the editor, it means the site is not ready to be updated. Once the update is available, you'll see a banner at the top of the editor with a link to get started.Additionally, keep in mind that only site owners and co-owners can perform the update. If you don't have one of these roles, you won't see the option to update. Who can perform the update? Only site owners and co-owners can perform the update.What will happen to my Premium plan?The Premium plan will stay connected to the site. This means you continue to benefit from all the features of your existing Editor X pricing plan, for as long as you choose to renew it. We’re also offering the option to switch to a Wix Studio plan, but note that this may mean losing some existing features.Can I still create a new Editor X site?No. As part of the transition process, you are no longer be able to create new Editor X sites.We recommend starting any new projects you get on Wix Studio.Can I go back to Editor X? No, once you update a site from Editor X to Wix Studio, you won't be able to revert to Editor X. For the time being, you can still access the site's old revisions (from the Site History page), but they will open in the Studio Editor.
