Wix Studio FAQs: Using the Wix Editor
As a Wix Studio user, you can choose to build a site on our brand new Studio Editor or, if you prefer, you can stick with our Wix Editor. FAQsBelow are some of the most common questions we've received from Wix Studio users about the Wix Editor. Can I move my sites between Wix Studio and the Wix Editor?It is not possible to move sites you have created in the Studio Editor to the classic Wix Editor. Likewise, classic Wix Editor sites in your account cannot be moved to the Studio Editor.I'm a professional/Partner, but I like using the classic Wix Editor. Can I continue building sites on it?Yes, once you switch to Wix Studio you can choose to build in the Wix Studio Editor, Editor X or the classic Wix Editor. There are some exclusive features that apply only to the Wix Studio Editor, like reusable apps or custom templates.Wix Editor, Editor X and Wix Studio sites are accessible via the Sites tab in your Wix Studio workspace, so you can continue to choose which Editor to build on, based on your needs for that particular project.I've only built sites with the classic Wix Editor. Will it be difficult to learn how to build with Wix Studio?With Wix Studio, you can enjoy the familiarity of building on an intuitive visual canvas with smooth drag and drop, using the out-of-the-box tools, like scale proportionally and AI responsiveness, or try out more complex design logic if you prefer. As with any new platform, there will be a short learning curve, so we recommend that you check out Wix Studio Academy's Essentials course to get started, but we'll provide you with everything you need to onboard and become an expert.If I use the Wix Studio workspace, will I lose out on hearing about Wix Editor product updates?In the new workspace you'll be first to know about the latest news, products, features, events and more, not just for Wix Studio—but for Wix Editor and Editor X too, so you won't miss out.Never miss an update with notification alerts in the Updates section of your dashboard, under the megaphone icon.Will existing Wix sites built on the other Editors be migrated to Wix Studio or stay as they are?Your Editor sites will not migrate to Wix Studio. The transition will change your workspace only. All sites will remain on their original Editor and are accessible through the Sites tab of the Wix Studio workspace.Are Wix Studio's Premium plans more expensive than those on the classic Wix Editor?Visit the Wix Studio Premium plans page for pricing and details.
